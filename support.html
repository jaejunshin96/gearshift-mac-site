Gearshift Support

Convert files with one key — right from Finder

Getting started

After you open Gearshift, a gear icon appears in the menu bar and a short tutorial opens. In Try It Yourself, drag the sample photo and press a key while dragging:

  • ⇧ Convert — change formats (PNG → JPG, MOV → MP4, video → GIF, DOCX → PDF…)
  • ⌘ Tools — compress, resize, rotate, remove backgrounds, merge PDFs…
  • ⌃ Actions — AirDrop, shelf, move, copy path, open in Terminal

Drop the file on a slot. When Gearshift has access to the source folder, the result is saved next to the original. Otherwise, the result is saved in Downloads; the original is never changed.

On the tutorial's last step, click Allow Home Folder… and then Allow. App Store apps may only write to folders you allow, so this lets Gearshift save results next to your files.

Without dragging

  • Select files in Finder → right-click → Services → Open Gearshift Wheel. To give it a shortcut, go to System Settings → Keyboard → Keyboard Shortcuts → Services.
  • Menu bar gear → Convert Files…
  • In a wheel opened this way: ←→ choose, ↩ run, ⇥ next wheel, esc close.

Frequently asked questions

The wheel doesn’t appear.

Press the key while you are already dragging, then move the pointer a little. Press ⌃ only after the drag has started — holding it before you click turns the click into a right-click. You can practice again from the menu bar: gear icon → How to Use….

My results were saved to Downloads.

Gearshift can only write inside folders you allow. Open Settings → Folders and add the folder (or your home folder). After that, results are saved next to the originals.

Which formats are supported?

Images: JPG, PNG, HEIC, AVIF, TIFF, BMP, GIF, PDF. PDF: PNG, JPG, TIFF, DOCX (text), TXT. Video: MP4, MOV, M4V, animated GIF, M4A. Audio: M4A, WAV, FLAC, AIFF, CAF. Documents: PDF, DOCX, RTF, TXT, HTML, ODT. Subtitles and tables: SRT, VTT, CSV, TSV. Any file or folder: ZIP, TAR.GZ; extract ZIP, RAR, 7Z, TAR. Formats that macOS can’t decode natively (for example MKV, WebM, AVI, OGG) aren’t supported.

Can I hide formats I never use?

Yes. Settings → Wheel Formats lets you hide or reorder formats for each kind of file.

I hid the menu bar icon. How do I get Settings back?

Open Gearshift again from the Applications folder; the Settings window opens.

How do I uninstall Gearshift?

Quit it from the menu bar icon and move it from Applications to the Trash. To remove its settings too, delete ~/Library/Containers/com.jaejunshin.fileconverter.

Does Gearshift collect any data?

No. Everything runs on your Mac and the app never connects to the internet. See the Privacy Policy.
